## hey, i'm camzzz 👋

Self-taught developer from **Lille, France**. I build **local-first software**: tools that run on your
own machine with no account, no cloud and no telemetry — offline AI studios, Windows internals
utilities, Android tweak apps and small security-research kits. Most of what I ship is a single
portable exe, or a single Python file you can read end to end.

```txt
now        → OptimizeKit (C++20 · Win32 · WebView2) and windclone, a from-scratch OS in C/asm
learning   → kernel land, low-level Windows, reverse engineering
principle  → offline first · reversible · no installer · no telemetry · readable source
```

## 🧰 what i build

- **Offline AI** — local chat, vision, image generation and voice, running entirely on your hardware
- **Windows internals** — tweaks, live monitoring, storage analysis, driver and firmware panels, all reversible
- **Android** — no-root toolkits, refresh-rate and clock control, Termux-only setups
- **Security research** — OSINT, scanners, static malware analysis, with readable reports
